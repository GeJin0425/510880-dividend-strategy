## 回测口径

- **510880**：使用前复权收盘价（`DIVIDENDS_510880` 分红列表），通过价格调整反映分红。
- **511260**：使用前复权收盘价（`DIVIDENDS_511260` 分红列表），通过价格调整反映分红。
- **行情口径**：新浪主源和腾讯备用源均返回未复权 OHLC；仅在 `fetch.py` 复权一次。`*_raw` 始终保留未复权报价，输出的 `meta.price_data` 记录来源、价格口径和已应用分红。腾讯只返回复权数据时会报错，不会把它当成原始报价。
- **模型限制**：当前引擎沿用前复权价格和100份整手计算仓位，并非真实份额加现金分红台账。补录分红会改变历史复权价格，进而可能改变此前的整手取整结果；因此权益变化不能直接等同于实盘收到的分红金额。
- **佣金**：万0.5（0.005%），单笔最低0.5元；ETF免征印花税。配置在 `pipeline/export.py` 的 `FEE_RATE` / `FEE_MIN`。
- **份额数据**：从上交所公开基金规模接口取得每日规模（亿元），用规模除以当日未复权收盘价还原份额（亿份），计算5日/20日对数变化以及20日变化的252日标准分。直接公布的 `TOT_VOL` 更精确，后续应持续归档替换近似历史。
- **资金流规则**：b1不受资金流限制；b2/b3要求 `flow_z20 >= 0`。
- **成交时点**：T 日收盘后用当日已知指标及份额数据确认信号，T+1 交易日以**前复权开盘价**模拟买卖；交易明细同时显示券商可核对的未复权开盘价。成交后每日权益均以收盘价估值，实盘仍可能存在滑点。
- **口径变更**：旧版本使用同日收盘或次日收盘成交，不能作为实盘执行参考；当前页面所有绩效均使用次日开盘成交，历史指标不可与旧版直接比较。
- 资金流指标需要约272个交易日预热，因此仪表盘和回测从首个有效 `flow_z20` 日期开始（历史数据不代表未来收益）。

## 维护：分红列表

`pipeline/fetch.py` 中的 `DIVIDENDS_510880` 列表记录了510880历年的（除息日，每份分红金额）。510880每年1月都会分红一次，**分红公告后需要在列表最前面新增一条 `(ex_date, amount)` 记录**——具体除息日和每份分红金额可在东方财富查询：搜索"510880" → 分红送配。

`DIVIDENDS_511260` 记录511260十年国债ETF的现金分红（2025年9月起开始分红，截至2026年9月共5次）。511260分红不定期，**公告后同样需要新增记录**。2026年9月18日除息，每10份12.747元，即每份1.2747元；来源为[基金分红公告](https://money.finance.sina.com.cn/fund/go.php/vAkFundInfo_JJGKXX/q/5553065.phtml)。

如果漏更新，前复权价格序列（以及由此派生的MA250、偏离度等全部策略信号）会从下一次除息日起悄悄产生偏差，且不会有任何报错提示——只有信号逐渐"跑偏"，很难第一时间察觉。

## 维护：数据日期与交易日历

导出前使用固定版本的 `exchange_calendars` XSHG 交易日历，按北京时间15:00判断最近已收盘交易日。行情、规模数据必须覆盖实际计算区间的每个交易日；重复日期、未收盘/未来日期、非交易日和陈旧尾部均拒绝发布，不会通过取交集或填充来隐藏缺失。

510880行情包含指标预热历史，规模包含资金流预热历史；511260没有生产指标预热，仅检查策略实际使用的完整日期区间。未使用的早期511260历史存在2018年8月17日无报价记录，未进行补造；使用区间内缺失任何一天仍会报错。

当前日历覆盖1999–2026，并核对了上交所2026年全年休市公告；国庆10月1–7日休市，10月8日开市，调休周末不算交易日。**新年度公告后需审核并更新 `market_sessions.py` 的覆盖范围及休市核对表**；未审核年份会停止导出，不能退化成普通工作日日历。

2026年10月1日本地修复、同一批原始输入的分红影响回放及验证细节见[修复报告](docs/research/2026-10-01-dividend-data-integrity.md)。
