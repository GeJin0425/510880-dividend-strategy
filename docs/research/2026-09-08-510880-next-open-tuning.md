# 510880 当前成交口径下的参数调优

## 结论

本次调优使用当前生产引擎重新搜索：收盘生成信号、下一交易日开盘成交、万0.5佣金、最低佣金0.5元、100份整手，并保留 b2/b3 的 `flow_z20 >= 0` 入口过滤。调参数据使用 2022-01-28 至 2026-09-07 的冻结审计快照，其中 2022--2024 为训练期，2025 年以后只作样本外验证。

训练期最优候选的年化提高明显，但在 2025 年以后只有 5 笔完整交易，优势仍需继续观察。经确认后，本次将候选 A 切换为生产参数，同时保留基线指标和这份调优报告用于后续复核。

## 当前基线

```text
b1=-1.67, b2=1.00, b2r=31.67, b3lo=0.00, b3hi=4.00
s1=14.00, s2=5.00, s2r=77.50, s3pk=6.00, s3dp=2.33
s4pr=3.50, s4r=67.50, cooldown=10
```

## 影子候选 A

这是第二个随机种子搜索中训练评分排名靠前、且样本外表现改善的候选，本次作为生产参数 A：

```text
b1=-2.50, b2=1.00, b2r=30.00, b3lo=0.00, b3hi=5.00
s1=16.00, s2=4.00, s2r=75.00, s3pk=6.00, s3dp=2.50
s4pr=4.50, s4r=67.50, cooldown=12
```

| 区间 | 当前基线年化 | 候选A年化 | 当前基线最大回撤 | 候选A最大回撤 |
|---|---:|---:|---:|---:|
| 训练期 2022-01-28--2024-12-31 | 38.1% | 41.5% | -5.8% | -6.3% |
| 样本外 2025-01-01--2026-09-07 | 21.0% | 22.1% | -5.7% | -5.7% |
| 全部冻结快照 | 31.7% | 33.5% | -5.8% | -6.3% |

样本外只包含 5 笔已平仓交易，+1.1 个百分点的年化提升还不能视为稳定优势。另一个独立搜索的训练最优候选，样本外反而只有 18.5%，说明直接追逐训练排名会过拟合。

## 参数变化的共同方向

两个独立搜索的高排名区域较多出现：`b2r≈30`、`b3hi≈5`、`s3pk≈5--6`、`s3dp≈2.5`，但冷却期和卖出阈值仍有明显分歧。这说明信号结构可能有方向性，但精确参数尚未形成可靠共识。

因此本轮采取：

- 将候选 A 切换为线上生产参数；
- 保留原基线结果，持续做实时影子对照；
- 等样本外累计至少增加若干笔完整交易后，再决定是否替换；
- 不把这次搜索结果描述成统计显著或未来收益承诺。

可复现实验：

```bash
PYTHONPATH=. python -m pipeline.tune_next_open --n 1000 --workers 8 --seed 42
PYTHONPATH=. python -m pipeline.tune_next_open --n 1000 --workers 8 --seed 7
```
